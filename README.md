# ひとつぶタスク（よる／あさ版）

朝と夜のルーティンを紙芝居式に1つずつ表示する、単体のWebアプリです。
リストで全部見えると圧倒されるので、今やるタスクだけが大きく表示され、タップで次へ進みます。

## 使い方

- `index.html` をブラウザで開くだけで動きます（サーバー不要）。GitHub Pagesでも公開できます。
- 「よる」と「あさ」の2つのリストがあり、開いた時間帯で最初のタブが決まります（5:30〜15:59は「あさ」、16:00〜5:29は「よる」）。手動での切り替えもできます。
- 紙芝居画面：カードをタップすると次のタスクへ。「もどる」で1つ戻れます。
- 一覧で確認：全部のタスクを一覧表示。終わったものにはチェック、今のタスクには「いまここ」が付きます。タップするとそのタスクから再開できます。
- タスクを編集：追加・名前変更・並び替え・削除ができます。JSONファイルへの書き出し／読み込みもできます（端末間の移行用）。

## 初期タスク

- よる（7件）：手を洗う／荷物を整理する／着替えを用意する／シャワーを浴びる／化粧水／ドライヤー／歯磨き
- あさ（8件）：水を飲む／顔を洗う／朝ごはんを食べる／歯磨きする／着替える／メイク／ヘアセット／荷物を準備する

## 保存について

- タスクと進捗はブラウザの localStorage に自動保存されます。
- 同じ日なら、閉じて開き直しても途中から再開できます。日付が変わると進捗だけ自動でリセットされます（タスク自体は残ります）。
- 保存先はその端末・そのブラウザ・そのURLごとです。別の端末には引き継がれないので、移したいときはJSON書き出しを使ってください。
- ブラウザのサイトデータを削除すると、保存したタスクと進捗も消えます。
